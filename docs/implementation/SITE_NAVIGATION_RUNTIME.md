# Site shell and grouped navigation

Baseline: `253a5e0ff7ed7cfff1e661b6c563a61626fdb260`. No author Markdown, legacy route, vendor, renderer or framework migration.

`asset/site-navigation-data.js` is the only interactive site-navigation source: six ordered domains, 35 nonempty groups and 180 articles. IDs derive from stable domain/group keys or complete route paths. `NAVIGATION_MIGRATION.json` retains the old 123 entries, explains the four invalid entries, and enumerates additions. All 119 valid old entries and all 176 top-level note Markdown documents are covered. The 20 author topic packages remain accessible through their historical article routes; internal mode Markdown and figures are not duplicate articles.

Two old `/note/` directory placeholders and two missing language `commonly-used` routes are removed from the menu only. Existing files/URLs are untouched. The old TS dropdown held only a CSS label: it is replaced by a real TypeScript group for the two existing files. Preact, React Native, Zustand, Mobx, Webpack and OpenClaw Skills chapters are grouped by project path. OpenClaw instance/templates belong to AI; point and reading notes belong to frontend. All other source documents are accounted for, including project indexes and Mermaid experiments. Add new article routes explicitly to the canonical data; `npm test` rejects missing coverage, duplicate IDs/paths, nonexistent routes, empty groups and project misclassification.

The single disclosure uses horizontal wrapping category/group rows, downward article cards, viewport-bounded internal scrolling and a sticky title/search row. Search filters all navigation titles, routes, domains and groups, with explicit global result counts; it does not search article bodies. Header tabs show an ordered prefix that fits intrinsic button widths; the right arrow always exposes all domains. Pointer hover uses 140ms selection and 300ms leave buffers. Click pins the panel; touch, Enter/Space, ArrowDown, left/right/Home/End in rows, Escape, outside pointer/focus, close and real route navigation are supported. Escape/close return focus to the opener. Auxiliary Baidu/CodePen/GitHub links remain in the disclosure footer. Docute's old menu is empty and its duplicate native shell controls are hidden.

`site-navigation.css` overrides the outer constraints after vendor/reader CSS: a full-width independent header, viewport-wide page and the existing content scroller fill the remaining space. Paragraphs keep 78–80ch limits; code, tables and figures may use available width and scroll locally. `topic-loader.js` reuses its existing chapter rail for ordinary Markdown as well as AI topics; identity checks rebuild ordinary headings after content replacement without observer loops. Desktop collapse and the mobile 52px expandable rail remain, as do AI mode icons/tabs, hashes, history positioning, complete view and printing. No original author files or vendor files were changed.

Checks: `npm test`, `npm run build`, `test:site-navigation`, `test:navigation`, and `test:browser` with the Mini's existing Playwright/Chrome. The site suite covers 320/375/390/768/1440/1920/2560px, 360px low-height cases, and 720 CSS px at scale 2 as the layout equivalent of a 1440px window at 200% zoom. This is emulated zoom layout, not an OS browser zoom control or physical-device test. It verifies title/search geometry, ordered tabs, last-item reachability, no page/article overflow, hover transition/reentry, touch/click, keyboard, search/empty/global-domain switching, real routes and ordinary headings. Existing suites cover 60 modes, 274 historical headings, diagrams, formula/code, failure recovery, races/cache, repeated history restores, and full-view print.

Evidence stays under ignored `evidence/`; it is not shipped publicly. Initial failure evidence is retained. Native screen-reader speech, physical phones, Safari/Firefox and exhaustive external-link availability remain untested.

# 三视图知识阅读样板：实现与手动验收

更新：2026-10-10。基线：`ai/next` 的 `1a8e978bf6cee4a4dfb10bf3ee5be207c0c31ea1`。

## 1. 范围和内容入口

- [Agent Loop](../note/ai/03-agent-loop.md)：保留原文件路径与原有小节标题；完整循环、职责、状态和出口仍在这里维护。
- [Tool Calling](../note/ai/03-tool-calling.md)：结构化提议、验证授权、执行结果、调用关联的主条目。
- [ReAct](../note/ai/03-react.md)：交替求解、相邻方法、条件和误区的主条目。

三个条目都提供“先用这条主线回答”、完整口语答案、书面精讲、概念图解。不是刷题系统，不维护课程进度，也不伪造项目经历。现有 18 个 Base 主题入口保持；新增两个文件属于 03 的知识拆分。

## 2. 实现形式

- 继续使用仓库已有 Docute，不新增 npm 依赖，不切换站点框架。
- 作者源仍为普通 Markdown。四个二级标题是小范围的展示约定；三级及以下标题组织视图内部章节。
- `docs/asset/knowledge-reader.js` 在渲染后识别完整标题结构。摘要始终可见，三个正文区增强为 ARIA tablist / tab / tabpanel。
- `docs/asset/knowledge-reader.css` 仅对样板类名应用阅读样式；普通文档不自动拆成 Tab。
- 首次默认口语；成功写入 localStorage 时记住视图偏好；存储受限时仍能阅读。URL 中 `view=oral|written|diagram` 优先于偏好。
- 原 Docute 的 `?id=...` 锚点优先打开目标所在面板。Tab 点击使用 replaceState 更新视图链接，不为每次切换生成新的历史条目；浏览器前后退仍主要用于文档导航。
- 支持左右键、Home、End 切换 Tab，选中 Tab 在键盘焦点序列中。打印样式展示全部视图。
- GitHub 和未加载增强脚本的站点顺序展示所有 Markdown 内容；不需要解析新 DSL。

## 3. 图表处理

8 张图源只在各自“概念图解”维护；书面正文链接到图解锚点，不另复制一份图。

沿用已有 Mermaid 主版本 CDN 引入，不增加新图表库；脚本改为 defer，避免阻塞正文脚本执行。替换原一次性 `done` 渲染逻辑，扫描未处理且不在隐藏面板中的 Mermaid 围栏；页内切换与路由更新后均可继续处理。

Mermaid 初始化使用 strict，关闭 HTML 标签；每图渲染隔离。成功时保留可展开的原始图源，解析失败时保留代码和错误说明。CDN 不可用时保留 Markdown 图源和文字解释。没有因本轮而修改系统安全设置。

原文已有 Mermaid 支持，但不能以此推断现有的全部历史图形都兼容 strict。非样板旧图若依赖 HTML 标签等行为，需要逐页复核；本轮未批量改写历史图源。

## 4. 单一知识来源与维护边界

- Loop 第 4 节、第 9.2 节保留定位与链接，详细解释分别维护在新条目；历史小节标题保留以降低断链风险。
- 术语索引的 Function call / Tool call、ReAct 指向新的主条目；AI 首页和全部文档索引同步新增入口。
- 摘要与口语是主知识的编辑表达，不是自动生成的保证。核心定义修改后应检查三种表达的一致性。
- 内容与图独立编写，借鉴参考站的信息组织，不复制其正文、配图或前端代码。
- 可见推理不等于完整内部计算；工具反馈不保证正确；Schema 合法不等于授权；循环不保证收敛。三视图均保持这些边界。

## 6. 手动验收入口

在检出本次文件的仓库根目录，使用已有 Python 3：

```sh
python3 -m http.server 9090
```

打开：

- `http://localhost:9090/docs/#/note/ai/03-agent-loop`
- `http://localhost:9090/docs/#/note/ai/03-tool-calling`
- `http://localhost:9090/docs/#/note/ai/03-react`

只需静态服务，不需要安装 npm 包。上述命令为用户手动启动说明，不代表已在用户电脑运行。

### 内容验收

- [ ] 三页摘要均显著、简短，足以指出核心机制与边界。
- [ ] 口语正文连贯且可以独立理解，不是术语清单或虚构经历。
- [ ] 书面正文可以追到主定义、因果机制、局限与来源。
- [ ] Loop 清楚画出回边及出口；Tool Calling 分开提议、执行与结果；ReAct 不与 Loop 或 SDK 混为一谈。
- [ ] 图解单独可读；图源、说明和正文没有相互矛盾的结论。

### 交互与显示验收

- [ ] 初次进入默认口语；切换 Tab 时摘要始终保留，页面不显示其他隐藏正文。
- [ ] 鼠标和键盘左右键/Home/End 均可切换，焦点可见；Tab 键可进入正文区。
- [ ] 复制带 `?view=diagram` 的链接，刷新仍展示图解；禁用存储后仍正常切换。
- [ ] 从正文的图解链接跳转，自动显示目标图解；刷新带 `?id=loop-control` 的链接仍可定位。
- [ ] 三页之间导航、前进/后退及重复点击，不出现重复 Tab 或空白正文。
- [ ] 三页 8 张 Mermaid 图均可显示；切换到普通章节再返回仍正常。
- [ ] 屏蔽 Mermaid CDN 或临时在本地破坏某张图语法，正文与其他图仍可阅读，失败图保留源代码。
- [ ] 手机约 375px 宽下三个 Tab 不溢出；大图和宽表可局部滚动；缩放未被禁用。
- [ ] 在现有前端知识页和 04 Context 页回归，确认未被错误拆成 Tab。
- [ ] 浏览器查找、目录锚点、打印及关闭增强脚本的回退可读。浏览器原生查找是否包含隐藏面板由浏览器决定，精确定位优先用目录或切换视图。

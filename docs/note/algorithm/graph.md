# 图：方向、权重、遍历与最短路径边界

> 审阅日期：2026-10-08。状态：概念与原创示例静态审阅，未运行。

## 1. 核心概念

图由顶点和边组成。有向性表示边是否具有方向，与权重无关。权重可以描述距离或成本；自环是一条从顶点回到自身的边，按边数计长度为 1，不是 0。

有向图强连通要求任意两点互相可达，不能只存在一个方向的路径。路径、游走和简单路径的术语在教材中可能不同，使用时明确是否允许重复顶点和边。

## 2. 表示方式

| 方式 | 空间 | 适用 |
| --- | --- | --- |
| 邻接表 | O(V + E) | 稀疏图、遍历 |
| 邻接矩阵 | O(V²) | 稠密图、直接检查边 |
| 对象间引用 | 取决于结构 | 也是合法图表示，需处理环 |

旧文称用节点引用表示图有问题，这不成立；困难是遍历与所有权，不是表示方式不合法。

## 3. BFS 示例

```js
function bfs(adjacency, start) {
  if (!adjacency.has(start)) return [];
  const visited = new Set([start]);
  const queue = [start];
  const result = [];
  for (let head = 0; head < queue.length; head += 1) {
    const node = queue[head];
    result.push(node);
    for (const next of adjacency.get(node) ?? []) {
      if (!visited.has(next)) {
        visited.add(next); // 入队时标记，避免重复入队
        queue.push(next);
      }
    }
  }
  return result;
}

const graph = new Map([
  ["A", ["B", "C"]],
  ["B", ["A", "D"]],
  ["C", ["A", "D"]],
  ["D", ["B", "C"]]
]);
// bfs(graph, "A") 预期 ["A", "B", "C", "D"]
```

契约假定邻接目标也在图中；外部图数据先校验引用。visited 是每次搜索自己的集合，不把上次 DFS 访问记录污染下一次 BFS。

## 4. DFS 与复杂度

DFS 可用递归或显式栈；递归深度受运行时限制。邻接表中每点每边有限次访问，常见复杂度 O(V+E)；若每次访问都线性查找顶点索引，实际实现可能更慢。

## 5. 最短路径

BFS 求无权图或等权边的最少边数路径。加权图不能直接沿用这个结论；非负权重可考虑 Dijkstra，含负权重需其他条件与算法。DFS 一般不保证最短路径。

## 6. 工程映射

依赖图、UI IR 引用图和任务 DAG 都可用图模型。DAG 必须无环；拓扑排序前检测循环依赖。不是所有业务工作流都必须是 DAG，重试流程可以有受控环。

## 7. 验证练习

测试菱形图、环、自环、孤立点、未知起点、重复边和断开的连通分量。检查每点访问一次，并说明遍历顺序如何受邻接顺序影响。

# Context Builder：选择、预算、压缩与记忆｜核心概要

## 核心模型

完整历史记录发生过什么，工作状态描述任务目前怎样，长期记忆保存跨任务信息，当前上下文则是这次调用实际可用的输入。存下信息与把它送进模型，是不同动作。

Context Builder 从规则、状态、工具描述和证据中选取内容，检查来源、权限、时间与预算，再组织成合法请求。相关性不能替代可信度；向量相似的资料也可能过期或不允许发送。

窗口不足时，可以局部读取、分页、保留句柄或压缩历史。压缩是有损变换，必须保留否定、撤销授权、未知结果和来源定位。长窗口、检索、压缩与 KV 缓存分别解决不同问题，不能互当替代品。

## 需要保留的边界

- memory.md 存在不代表它已进入本轮输入。
- 摘要不能把历史批准变成当前许可。
- 没有所有 Agent 通用的固定压缩比例或阈值。

## 本主题负责解释什么

本主题维护信息生命周期、输入装配与压缩；检索和长期记忆更新归 06，计算缓存归 13。

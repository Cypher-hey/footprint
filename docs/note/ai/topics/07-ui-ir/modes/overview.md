# AI 原生界面：Catalog、UI IR、Event IR 与可信执行｜核心概要

## 核心模型

UI IR 是应用定义的中间表示：作者或模型描述允许的组件与内容，程序校验后渲染。Catalog 提供可用组件、属性、组合与语义约束；它可以基于普通组件库，不必复制两套实现。

Flat IR 用节点映射与 ID 引用表达结构，降低文本嵌套，却没有消除逻辑层级。除了字段类型，还需检查缺失引用、环、根可达性和组合约束。共享节点与循环引用不是同一件事。

界面事件描述交互意图，领域层和运行时按当前状态决定处理，服务端落实实际权限。确定性的转换不意味着模型或网络整体确定。采用 IR 的收益是受控生成、复用与迁移，代价是维护合同和适配器，不是所有页面都需要它。

## 需要保留的边界

- Flat 不代表无层级或天然无环。
- UI 按钮可见不能证明用户具有权限。
- 公开产品的界面相似不证明内部使用同一 IR。

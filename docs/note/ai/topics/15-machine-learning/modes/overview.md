# 机器学习基础：数据、目标、优化与泛化｜核心概要

## 核心模型

模型用参数描述一类输入输出映射，训练根据样本与目标选择参数。特征表示输入，标签提供任务信号，超参数控制模型或训练设置。目标若选错，优化得更好也可能偏离实际用途。

前向计算得到预测，损失度量偏差，反向传播求梯度，优化器决定更新。监督、自监督、无监督和强化学习采用不同信号与交互方式，可以组合，不能把任何反馈都称为 RL。

训练表现说明拟合，泛化需要面向目标分布的新数据评价。预处理也属于拟合，必须避免泄漏；验证集用于选择，反复针对测试修改则破坏独立性。指标、阈值、类别分布和概率校准共同决定如何解释分数。

## 需要保留的边界

- 自监督并非没有监督信号。
- 反向传播求梯度，优化器使用梯度，二者不同。
- 99% 准确率可能来自完全忽略少数类。

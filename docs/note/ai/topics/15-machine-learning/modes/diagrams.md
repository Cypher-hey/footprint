# 机器学习基础：数据、目标、优化与泛化｜概念图解

## 读图主线

机器学习通过数据与目标调整模型；训练拟合、验证选择与测试评价各有边界，损失下降不自动证明泛化。

先读整体边界，再打开内部职责或时间变化；图是简化机制模型，不是实际运行记录。所有图与系统阐述共享同一份源文件。

<a id="figure-01"></a>

## 图 1：使用模型与训练模型分开看

训练路径生成参数，使用路径用参数预测；新输入本身不自动触发学习。

[图 1：使用模型与训练模型分开看](../figures/figure-01.mmd "footprint:figure")

上半部是使用已经学得的映射；下半部是获得参数的过程。下一步的问题是：训练如何判断哪组参数更好？这就需要明确目标和损失。

[结合正文解释阅读](explanation.md#figure-01)

<a id="figure-02"></a>

## 图 2：把图 1 的“学习过程”打开

从预测到损失再到梯度和更新，回边改变参数；这与应用工具反馈循环不同。

[图 2：把图 1 的“学习过程”打开](../figures/figure-02.mmd "footprint:figure")

反向传播利用链式法则计算梯度；优化器决定怎样用梯度更新。学习率控制步长，batch 是一次梯度估计所用的样本集合，epoch 表示对训练数据的一次遍历约定。它们不是同一个参数。

[结合正文解释阅读](explanation.md#figure-02)

<a id="figure-03"></a>

## 图 3：数据流中哪里允许反馈

验证允许影响方案选择，保留测试不能悄悄反馈进开发；预处理同样只从允许的数据中拟合。

[图 3：数据流中哪里允许反馈](../figures/figure-03.mmd "footprint:figure")

验证结果可以影响下一轮选择，因此它不是完全未参与开发的信息。保留测试集用于评价冻结的方案；若看完测试结果又针对它调整，就应承认该集合已参与开发。缩放器、特征选择等从数据估计出的预处理也属于拟合过程，不能先用全量数据计算后再切分。

[结合正文解释阅读](explanation.md#figure-03)

## 图没有承诺什么

- 自监督并非没有监督信号。
- 反向传播求梯度，优化器使用梯度，二者不同。
- 99% 准确率可能来自完全忽略少数类。

## 1. 学习的对象：从样本到可复用的映射

传统程序可以直接写出输入到输出的规则；学习系统则先限定一类可调整的映射，再用数据选择其中较合适的一个。“学习”在这里不要求类人的理解，而是训练过程改变了模型对输入的处理方式。

| 基础对象 | 定义 | 与相邻对象的关系 |
| --- | --- | --- |
| 样本 sample | 一次可用于学习或评估的观测 | 常含输入，也可能含目标 |
| 特征 feature | 输入中被用于预测的属性或表示 | 可以人工构造，也可以由网络学习 |
| 标签 label | 监督任务提供的目标 | 是训练信号，不保证标注无误 |
| 参数 parameter | 模型内部被优化的数值 | 与训练前选择的超参数不同 |
| 超参数 hyperparameter | 控制模型或训练方式的设定 | 如学习率、树深度；通常由验证过程选择 |

### 1.1 把任务写成目标

把输入记为 x，目标记为 y，模型为 fθ(x)，其中 θ 表示全部可训练参数。损失 L(fθ(x), y) 是预测与目标之间的代价；最小化损失为参数调整提供方向。常见训练目标是在许多样本上求平均损失，而非只让某一条样本正确。

“损失越低越好”的前提是损失确实表达了想要的行为。训练数据和目标函数共同规定模型被鼓励学习什么，算法不会自动修正错误的业务目标。

“预测哪篇知识笔记有用”还不是完整目标：有用是被点击、被收藏、解决了问题，还是事实可靠？若用点击作为标签，模型可能学习标题吸引力，而不是知识价值。代理指标与真实目标的差距会进入系统行为。

| 任务 | 输出 | 常见目标示意 | 易忽略的问题 |
| --- | --- | --- | --- |
| 回归 | 连续数值 | 平方误差、绝对误差 | 异常值与单位尺度 |
| 分类 | 类别或概率 | 交叉熵 | 类别不平衡、阈值与校准 |
| 排序 | 候选顺序 | 成对/列表排序损失 | 位置偏差、曝光偏差 |
| 表示学习 | 向量表示 | 重建、对比等目标 | 相似性是否符合下游用途 |
| 序列生成 | token/动作序列 | 序列似然、奖励等 | 局部目标与整体成功不一致 |

## 2. 训练信号从哪里来：四种学习范式

监督学习使用输入与目标标签；无监督学习从未显式标注目标的数据中找结构，如聚类或降维。自监督学习从数据本身构造训练信号，例如遮盖部分内容或预测后续 token；它不是“没有监督信号”，而是信号不一定由人工逐条标注。

强化学习在状态、行动和反馈之间优化策略。奖励可以延迟，行动会改变后续观察；它与静态样本分类不同。深度强化学习只是把深度模型用于其中，并不是强化学习的唯一形式。

这些边界在实际系统中可组合：预训练使用自监督目标，后训练使用示范或偏好，应用运行时再用工具反馈；不能把所有阶段都统称为 RL。

<a id="section-03"></a>

## 3. 模型家族不是升级等级

线性/逻辑模型适合透明的基线；树和集成方法常用于结构化特征；神经网络学习复杂表示。选择依赖数据规模、特征结构、延迟、可解释性和维护成本。

模型复杂度提升通常扩大可表达的函数集合，但不保证泛化提高。数据少、标签噪声大或部署分布变化时，复杂模型也可能更难诊断。先建立简单基线，是为了得到比较坐标，不是断言简单模型永远更好。

<a id="section-04"></a>

## 4. 参数怎样更新：前向、反向与优化器

前向计算使用当前参数得到预测；损失衡量偏差；梯度描述各参数微小变化时损失如何变化；优化器利用这些局部信息决定更新。反向传播负责高效求梯度，优化器负责使用梯度，二者不能互相替代。

<a id="figure-02"></a>

[图 2：把图 1 的“学习过程”打开](../figures/figure-02.mmd "footprint:figure")

反向传播利用链式法则计算梯度；优化器决定怎样用梯度更新。学习率控制步长，batch 是一次梯度估计所用的样本集合，epoch 表示对训练数据的一次遍历约定。它们不是同一个参数。

自写单样本例子：y_hat = w×x+b，L=(y_hat-y)²。令 x=2、y=5、w=1、b=0，误差为 -3，梯度分别为 -12、-6。学习率取 0.1 后，w=2.2、b=0.6，新预测约为 5。

这个恰好拟合单样本的算例只说明梯度更新，不说明模型获得了可靠预测能力。新样本的规律可能不同；多参数非凸目标也不保证一次更新或有限次更新到达全局最优。算术核对与训练实验是两种证据。

<a id="section-05"></a>

## 5. 为什么损失下降仍不足以证明有用

损失通常需要便于优化；指标用于评估任务；业务结果反映实际效用。三者可相关，但不相等。

二分类中，TP/FP/FN/TN 分别表示真阳性、假阳性、假阴性和真阴性。precision = TP/(TP+FP)，recall = TP/(TP+FN)。分母为零时应明确评估约定，不能默默产生“满分”。

把“不相关资料”判成相关会增加上下文噪声；把关键资料漏掉则会失去证据。阈值改变 precision/recall 的取舍，需要结合用途，而不是只看 accuracy。若 99% 样本属于同一类，始终预测该类也能有 99% accuracy，但可能完全没有识别少数类的价值。

<a id="section-06"></a>

## 6. 泛化：把“学会样本”与“适用于新数据”分开

泛化关注模型在目标分布的新数据上的表现。训练集只是有限观测，可能包含偶然关系、噪声和偏差；记住这些细节能降低训练损失，却未必帮助处理新输入。

<a id="figure-03"></a>

[图 3：数据流中哪里允许反馈](../figures/figure-03.mmd "footprint:figure")

验证结果可以影响下一轮选择，因此它不是完全未参与开发的信息。保留测试集用于评价冻结的方案；若看完测试结果又针对它调整，就应承认该集合已参与开发。缩放器、特征选择等从数据估计出的预处理也属于拟合过程，不能先用全量数据计算后再切分。

| 数据 | 用途 | 常见误用 |
| --- | --- | --- |
| 训练集 | 参数更新 | 把训练表现作为泛化证据 |
| 验证集 | 选择模型与超参数 | 过度反复选择，间接过拟合 |
| 测试集 | 独立评估 | 看完结果继续调方案，却仍称独立 |
| 部署数据 | 实际任务分布 | 假设永远与离线数据一致 |

划分必须匹配真实部署问题。同一文档的近重复片段分散到训练和测试，会高估迁移能力；预测未来时随机打散时间可能泄漏未来信息；同一用户的高度相关样本可能需要按用户分组。

过拟合表现为对训练数据适应过强、对新样本效果较差。训练/验证曲线分离是线索，不是所有异常的唯一解释；标签错误、预处理差异和分布漂移也需排查。[Google 的说明](https://developers.google.com/machine-learning/crash-course/overfitting/overfitting)提供了直观图解。

<a id="section-07"></a>

## 7. 控制拟合与理解不确定性

正则化通过参数约束、数据增强、早停等机制限制某些拟合倾向。它不是越强越好，过强可能使模型连训练规律都无法表达。偏差—方差是一种分析框架，不应机械推广为现代大模型所有性能曲线的定律。

模型给出的 0.9 分数也不必然意味着长期正确率 90%。校准关注预测概率与实际频率的关系；分布变化后原有校准可能失效。LLM 的 token 概率尤其不能直接当作整段事实正确的置信度。

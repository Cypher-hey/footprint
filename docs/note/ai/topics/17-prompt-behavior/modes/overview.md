# 提示与模型行为：指令、示例、证据和不确定性｜核心概要

## 核心模型

Prompt 广义指引导当前行为的输入，工程中也常狭义指任务说明。提示设计应说明目标、范围、依据、输出和缺证处理，而不只是要求模型‘专业准确’。输入改变条件分布，但不是强制访问控制。

上下文示例帮助说明任务映射与风格，检索证据支持当次事实，状态说明已经发生什么。示例可能引入位置或文风偏差，证据也可能过期；Context Builder 负责按任务组织这些材料。

更长的推理文本和再次自查都不自动提供独立验证。应拆分事实错误、引用不支持、任务偏离和能力虚报，定位是缺材料、裁剪问题还是模型误用。表达不确定性时，说明证据范围比未经校准的百分比更可靠。

## 需要保留的边界

- 角色扮演不能生成事实依据。
- XML 标签不是权限隔离机制。
- 同一模型再次赞同自己不构成独立证据。

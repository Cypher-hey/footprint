# AI 应用全景：把模型、知识、控制与证据连接起来｜核心概要

## 核心模型

AI 应用可以从模型计算、知识供给、运行控制、交互表达和结果验证五个视角分析。它们是职责视角，不是必须部署的五个服务，也不要求每个应用都使用 Agent 或 UI IR。

信息流说明哪些材料成为输入，控制流说明哪些步骤可以发生。模型产生提议后，内容检查与动作授权沿不同边界处理；工具结果更新状态，再由装配过程选择是否进入下一次调用。

来源版本、产物 revision、运行记录、批准和业务操作表达不同事实。排查问题时先确认信息在哪一层丢失、控制在哪一层拒绝、证据支持到哪里，再回到相应主条目。Base 形成稳定概念网，Advance 围绕具体假设、反例和实证深化。

## 需要保留的边界

- 五视角不要求五个独立服务。
- 更自主不自动等于更先进或更适合。
- 一次项目成功只支持其观察范围内的结论。

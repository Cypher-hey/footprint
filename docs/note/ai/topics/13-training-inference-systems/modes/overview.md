# 深入模型层：后训练、蒸馏与推理系统｜核心概要

## 核心模型

后训练在预训练基础上进一步塑造行为。SFT 利用示范，偏好方法利用相对选择，RL 利用奖励，蒸馏转移教师行为或表示；它们不是严格互斥分类。LoRA 限定增量参数化方式，可以用于 SFT，而不是替代训练目标。

推理系统负责请求调度、模型计算和状态复用。Prefill 处理已有输入，decode 延续生成，KV Cache 复用历史位置的计算状态。模型权重、KV、激活与服务开销共同决定容量，权重放得下不代表高并发可用。

量化、批处理、并行与缓存解决不同瓶颈，可能改变质量或等待。比较需要固定工作负载、精度、硬件、缓存条件和质量门槛，同时看首 token 延迟、总延迟、吞吐与尾延迟，不能相乘产品宣传中的加速倍数。

## 需要保留的边界

- 减少某层可训练参数不等于整模型显存同比下降。
- KV Cache 不是应用长期记忆。
- 更低比特不保证所有硬件更快。

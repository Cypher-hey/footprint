# 多模态基础：图像、语音、视频与跨模态表示｜核心概要

## 核心模型

模态是信息表达通道，如文字、图像和音频。多模态理解、检索与生成是不同任务；上传入口相同不能证明内部模型相同，也不能推断支持全部模态能力。

图像可经缩放、裁剪、分块和编码进入计算；音频可以先转文字再处理，也可直接参与多模态计算。级联便于检查中间结果，却可能丢失语气或时间信息；直接建模也不必然在所有任务上更好。

跨模态对齐提供可比较关系，融合使不同信号共同影响计算。结论应保留区域、时间戳、抽样和来源：几张关键帧没有某事件，不代表全程没有。生成媒体是产物而非现实证据，OCR 或转录中的命令仍属于外部数据。

## 需要保留的边界

- OCR 读到字不等于理解整张图表。
- ASR 正确不等于识别了说话者身份。
- 媒体生成逼真不证明事件真实发生。

## 本主题负责解释什么

本主题维护模态、编码、对齐融合、级联和媒体证据边界；不覆盖完整视觉或语音学科，检索和安全归 06、09。

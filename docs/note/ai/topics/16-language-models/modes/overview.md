# 语言模型机制：Token、表示、Attention 与自回归生成｜核心概要

## 核心模型

Tokenizer 将文本编码为 token ID，embedding 将 ID 映射成向量。Transformer 多层更新这些表示，再产生词表 logits；解码策略依据分布选择输出。token ID 的数值距离不直接表达语义距离。

Attention 用 Q、K 的匹配得到权重，再组合 V；FFN 对各位置作非线性变换，残差与归一化连接各层。因果掩码限制未来信息，位置机制提供顺序信息。Attention 是重要部分，但不是模型全部计算。

训练时可在合法掩码下并行计算多个位置目标；常规生成时未来 token 未知，需要逐步延续。KV Cache 复用计算状态，不是事实记忆；高 token 概率也不等于整段答案真实。模型内部生成循环与外层工具行动循环可以嵌套。

## 需要保留的边界

- 向量维度不是可数的人类概念数量。
- 注意力权重不能直接视为忠实因果解释。
- 贪心每步最大不保证整段序列最优或事实正确。

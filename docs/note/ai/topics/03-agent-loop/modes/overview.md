# Agent Loop：目标、行动与反馈构成的运行机制｜核心概要

## 核心模型

Agent 是根据观察选择行动并与环境交互的系统。LLM-based Agent 中，模型提出回答或行动，Runtime 组织调用与状态，Tool 执行获准操作；三者不能合并为‘模型自己做了事情’。

最小闭环是：组织输入 → 模型输出 → 校验并执行行动 → 记录观察 → 更新状态与输入 → 下一次决策。回到相同控制步骤时，模型可见的信息可能已经改变；结果只存进日志而没进入后续输入，就不能期待它影响决策。

Loop 必须有完成、等待、取消、阻塞与预算出口。反馈并不保证进步，模型宣称完成也不代替结果检查。Tool Calling 负责行动交接，ReAct 是一种推理与行动结合的方法；普通循环通常不更新模型权重。

## 需要保留的边界

- 重复调用不自动构成有效反馈。
- 一项任务只调用一次模型也可能由 Agent 系统完成。
- 安全 policy 与强化学习中的 policy 不是同一含义。

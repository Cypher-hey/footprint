# RAG 与长期记忆：从找得到到用得对｜概念图解

## 读图主线

RAG 用可更新的外部资料支持生成；从检索相似到结论成立，还隔着权限、版本、上下文装配和引用支持度。

先读整体边界，再打开内部职责或时间变化；图是简化机制模型，不是实际运行记录。所有图与系统阐述共享同一份源文件。

<a id="figure-01"></a>

## 图 1：先看检索增强的最小关系

最小关系是问题与候选证据共同进入生成；箭头只说明供给，不保证模型正确使用。

[图 1：先看检索增强的最小关系](../figures/figure-01.mmd "footprint:figure")

增强发生在输入条件上，不要求每次重新训练模型。图中从候选到回答的箭头只表示信息被提供，不保证模型准确使用了证据。

[结合正文解释阅读](explanation.md#figure-01)

<a id="figure-02"></a>

## 图 2：把资料库和检索分别打开

上半部维护索引，下半部服务查询；权限是贯穿约束，不能因为图简化就推迟到外传之后。

[图 2：把资料库和检索分别打开](../figures/figure-02.mmd "footprint:figure")

上半部是索引维护路径，下半部是一次在线查询路径。离线准备解决可查找性，在线流程解决当前问题的证据选择；任何一步成功都不等于端到端正确。

[结合正文解释阅读](explanation.md#figure-02)

<a id="figure-03"></a>

## 图 3：来源与结论之间需要可检查的映射

定位片段与支持断言是两条职责。读到真实 URL，不代表已经完成证据检查。

[图 3：来源与结论之间需要可检查的映射](../figures/figure-03.mmd "footprint:figure")

引用标识只解决“指向哪里”；片段到断言的箭头才需要检查“是否支持”。缺少这条支持关系时，添加更多链接也不能把生成文本变成可靠知识。

[结合正文解释阅读](explanation.md#figure-03)

## 图没有承诺什么

- 同维度向量未必来自兼容语义空间。
- 更多引用不能弥补引用不支持断言。
- 权限约束应在数据暴露前生效，不应最后才隐藏。

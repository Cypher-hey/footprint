# RAG 与长期记忆：从找得到到用得对｜核心概要

## 核心模型

RAG 将检索材料作为生成条件，不要求每次重新训练模型，也不要求一定采用向量数据库。关键词、向量、结构化查询和混合检索分别利用不同信号，适用性需要结合资料与问题判断。

离线链路负责解析、分块、元数据和索引；在线链路负责召回、重排、证据装配与生成。分块决定限定条件是否一起出现，重排只能重排已找到的候选，长上下文也不能修复根本没有召回的证据。

答案还需要把具体断言映射到可定位来源。相似度高不等于支持结论，来源存在不等于当前有效。长期记忆可以复用检索组件，但还需要实体、时间、冲突解决与删除策略；它不是 RAG 的同义词。

## 需要保留的边界

- 同维度向量未必来自兼容语义空间。
- 更多引用不能弥补引用不支持断言。
- 权限约束应在数据暴露前生效，不应最后才隐藏。

# Agent 可靠性与安全：把权限和恢复放在模型之外｜核心概要

## 核心模型

模型选对工具仍可能越权、重复写入或泄露资料。外部内容进入上下文、模型提议进入执行、服务访问用户数据，都是需要单独控制的边界。认证、对象授权与当前动作批准不能合并为一个登录状态。

重试时需要识别同一业务意图。幂等保证依赖服务端对键、请求指纹、结果和业务效果的处理合同，不是客户端生成 UUID 就完成。写入超时可能已成功，应保留未知状态并查询或核对。

提示注入可能把数据伪装成指令；来源标注只能帮助判断，仍需最小权限、受控出口和高影响动作批准。日志本身也会复制敏感数据。安全结论必须说明测试条件，不能以一次正常成功或一条过滤规则宣称绝对安全。

## 需要保留的边界

- 一个 UUID 不会自动使下游业务幂等。
- 补偿不一定还原时间、费用和外部可见性。
- 角色提示词和工作目录分离不自动构成安全沙箱。

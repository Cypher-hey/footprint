# Evals 与可观测性：让改进成为可验证的判断｜概念图解

## 读图主线

评测把目标、输入分布、判据与观察联系起来；观测帮助定位原因，多维结论不能被单个漂亮分数替代。

先读整体边界，再打开内部职责或时间变化；图是简化机制模型，不是实际运行记录。所有图与系统阐述共享同一份源文件。

<a id="figure-01"></a>

## 图 1：评测不是只给答案打分

任务条件与独立判据共同限定结论；只观察最终答案会丢失行动风险。

[图 1：评测不是只给答案打分](../figures/figure-01.mmd "footprint:figure")

结果与行为都进入判定：答案正确却越权执行，和未越权但答错，是两种不同失败。评价规则必须先承认这种区别，才能选择合适指标。

[结合正文解释阅读](explanation.md#figure-01)

<a id="figure-02"></a>

## 图 2：检查结果组成向量，而非立刻压成总分

各支路组成质量向量；硬边界失败不能让文风或速度加分抵消。

[图 2：检查结果组成向量，而非立刻压成总分](../figures/figure-02.mmd "footprint:figure")

图中的各支路回答不同问题。高风险禁止行为可设为硬门禁；其失败不能被更好的文风或更低的延迟抵消。是否可以合成总分，取决于是否存在明确且合理的权重和淘汰规则。

[结合正文解释阅读](explanation.md#figure-02)

## 图 3：把任务级失败下钻到阶段

从聚合指标下钻到具体运行轨迹与阶段证据，同时避免无限复制私人原文。

## 图没有承诺什么

- 小样本的分数上升不证明普遍提升。
- 零次观察到越权不证明对所有攻击安全。
- 多次运行同一道题不是等量独立新任务。

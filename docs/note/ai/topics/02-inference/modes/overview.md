# 推理请求：输入、采样、结构化输出与流式传输｜核心概要

## 核心模型

推理请求是应用与模型服务之间的计算合同。一次 HTTP 响应可能包含文本、结构化对象、工具提议或托管流程的结果，因此请求完成不能直接当作用户任务完成。

模型计算分布，解码策略选择输出；温度与候选截断影响选择，但不能作为正确性或跨环境逐字复现的保证。输出预算和停止状态也必须被解释，截断内容不能被当成完整答案。

接收结果时，先处理字节和协议事件，再检查对象结构与业务含义。流式预览可逐步展示，外部动作则必须等待完整参数、业务检查及授权。结构合法、事实成立和动作获准应保持独立。

## 需要保留的边界

- 一个网络 chunk 不是一个完整 JSON。
- 合法 JSON 不等于真实结论。
- temperature=0 不构成跨服务版本的确定性承诺。

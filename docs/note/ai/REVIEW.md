### 本轮纠正的具体表述

- 多 Agent 时间算例改为相同开销口径：串行工作 15 分钟，加同样 4 分钟协调为 19；并行为 9。若单 Agent 无协调成本，则其比较基线另记为 15。
- Flat IR 的多父引用并不自动保证 DAG；只有无环才构成有向无环图，树结构还需根可达性和父节点约束。
- temperature=0 的 API 约定与正温度公式区分，避免把它写成数学除零。
- 生成阶段说明第一枚 token 的分布可来自 prefill，不把示意图误读为必需重复处理输入。
- 删除流式 JSON 例子中关于“第三行中文引号”的无对应指代。
- 规范不再要求同一个案例贯穿全文，改为概念主线和局部例证。

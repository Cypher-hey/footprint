## 5. Base 与 Advance

Base 维护稳定定义、基本机制、区别与边界；Advance 围绕具体问题展开推导、实现变体、取舍和实证。一个主题可同时拥有两层，但主定义只维护一处，其他地方链接回去。

当前[Advance 页面](ADVANCE.md)是问题与来源索引，不是假装已完成的高级正文。新增专题应说明相对于 Base 新回答了什么。

## 6. 阅读与回顾方式

快速回顾看定义与结论；需要理解看机制、图表和完整例子；遇到实际问题看边界与关联；要继续深入看带说明的来源。短代码、算例和故障案例用于印证，不要求在此仓库完成课程或部署项目。

实践项目可以反向链接相关知识点；知识页可保存非敏感的条件、观察与结论范围。没有证据时标明待印证，不补造成功经验。

## 7. 来源与表达

主题组织参考 [Bojie Li 的 AI Agent 书籍固定版本](https://github.com/bojieli/ai-agent-book/tree/dbc046eb896ac4e39aa19c7774c8bf49583b89a6)。正文为独立编写，不复制其配图或实验。协议与理论优先链接官方资料及原始论文；自定义架构、数据和预算明确标注。

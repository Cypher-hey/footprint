# AI 基础全景：模型、数据、推理与应用系统

> 类型：Base / 总览。核查：2026-10-08。范围：面向 AI 应用与 Agent 工程；不声称覆盖整个 AI 学科。
> 本页提供概念主线，机制细节链接到独立条目；不是课程进度表或项目任务书。

## 快速回顾

- AI 是宽泛研究与应用领域；机器学习是其中一类方法，深度学习是机器学习中的一类方法。
- 大语言模型是一种模型；Agent 是围绕目标、观察和行动形成反馈的系统组织方式。二者不在同一分类维度。
- 训练改变参数；推理使用已有参数计算；外部知识和记忆由应用管理。一次回答可同时依赖三者。
- 模型“能生成”与系统“能可靠完成”之间，还隔着数据、工具、权限、状态和验证。
- 本知识库以“概念主定义＋关联专题”维护认知，不用框架名称代替机制。

## 1. 领域、方法、模型、系统：四层分类

| 层次 | 例子 | 判断它的依据 |
| --- | --- | --- |
| 领域/任务 | 语言、视觉、语音、规划、机器人 | 研究什么问题 |
| 方法 | 搜索、规则推理、统计学习、深度学习、强化学习 | 用什么方式求解 |
| 模型 | 线性模型、树模型、Transformer 等 | 输入怎样映射到输出 |
| 应用系统 | 搜索助手、知识管理、代码 Agent | 怎样组织数据与行动 |

这不是一棵互斥分类树。强化学习可以使用深度网络；视觉模型可以使用 Transformer；Agent 也可以包含规则规划、检索和确定性程序。因此“它属于 Agent，所以不是机器学习”是分类轴混淆。

传统机器学习并未因为 LLM 出现而失去位置。结构化预测、排序、异常检测等任务，仍可以由简单模型或规则完成。模型越大、系统越自主，都不是能力更匹配任务的充分条件。

## 2. 从数据到行为的知识地图

```mermaid
flowchart LR
    D["数据与目标"] --> T["训练与评估"]
    T --> W["模型参数"]
    W --> I["推理计算"]
    C["上下文与外部证据"] --> I
    I --> O["文本、结构或行动提议"]
    O --> R["应用运行时"]
    R --> E["工具与外部环境"]
    E --> C
```

图中参数来自训练，外部证据进入当前请求；环境反馈重新进入上下文，不自动意味着权重被更新。真实系统可以加入在线学习，但那需要显式训练与发布流程。

## 3. 五个经常被混用的词

| 词 | 本知识库中的含义 | 不等于 |
| --- | --- | --- |
| 知识 | 可支持判断的事实、关系和规则 | 任何流畅输出 |
| 参数 | 训练得到的数值状态 | 可直接查询、逐条维护的数据库 |
| 上下文 | 一次调用可用的信息 | 全部历史与永久记忆 |
| 推理 inference | 执行模型计算 | 必然正确的逻辑论证 |
| 推理 reasoning | 分析、演绎等问题求解行为 | 单一、公开可观察的内部过程 |

模型生成的解释可以帮助沟通，但不能当作其内部计算过程的忠实日志。系统审计优先依据可观察的输入、工具调用、结果和产物。

## 4. 同一个知识问答，三种补充方式

假设应用需要回答“仓库现在怎样组织缓存模块”，资料上周刚变更：

1. 把相关文件放进当前请求：改变上下文，模型参数通常不变。
2. 把文件保存并建立检索索引：改变外部知识供给，相关资料在需要时进入请求。
3. 用样本适配模型：改变参数或适配器，使某类行为更符合目标；更新事实仍可能需要检索。

这三种方式可组合。只因为模型答对了新事实，不能判断它已被训练；只因为微调过，也不能保证它知道最新仓库状态。[提示与上下文学习](17-prompt-behavior.md)和[后训练](13-training-inference-systems.md)分别解释这些边界。

## 5. AI 应用的可靠性来自哪里

输入质量影响问题是否清楚；检索影响证据是否可用；模型影响理解和生成；工具契约影响能否执行正确动作；权限决定哪些动作允许；验证决定怎样确认结果。

一个环节出错可能在其他环节表现出来。引用错误不一定是语言模型“不够强”，也可能是检索用了旧版本、来源 ID 丢失或 UI 映射错误。分析时应沿数据路径回查，而不是把所有失败归给模型。

## 7. 常见误解

- “大模型就是概率接龙，所以不能解决复杂问题”：生成目标不能直接限定训练后涌现的全部行为，也不能证明它具备任意可靠推理。
- “能调用工具就是自主 Agent”：工具调用也可处于固定流程中；自主程度取决于决策与控制结构。
- “更长上下文等于永久记忆”：上下文可用性、持久化、检索和遗忘是不同问题。
- “Base 只需要记名词”：基础应能解释相邻概念的关系，否则回顾时仍只能恢复标签。

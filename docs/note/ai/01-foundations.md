# AI 基础：从机器学习到大语言模型

> 学习层级：入门。前置：函数、数组、概率直觉。维护日期：2026-10-08。
> 验证状态：概念与来源审阅；自写单样本梯度算例的 3 条数值断言通过；无模型训练或推理实测。

## 1. 这章解决什么

先建立一张概念地图，避免把 AI、机器学习、LLM 与 Agent 当作同义词。贯穿案例是一个把技术材料转成可交互学习卡片的应用。

## 2. 核心关系

| 概念 | 关注的问题 | 卡片应用中的位置 |
| --- | --- | --- |
| AI | 如何让系统表现出智能行为 | 整个应用能力 |
| 机器学习 | 怎样从数据学习规律 | 内容分类或推荐模型 |
| 深度学习 | 用多层参数化网络学习表示 | 语言、图像模型的常见基础 |
| LLM | 如何对语言等序列建模与生成 | 解释、提取、改写、规划 |
| Agent | 如何根据观察选择行动并形成反馈循环 | 查资料、修订、验证的调度 |

这是教学分类，不是所有研究领域唯一的定义。模型能力与应用可靠性也不是同一件事。

## 3. 训练与推理

训练调整参数；推理在给定输入和已有参数下计算输出。把一份文档放进上下文通常不会修改模型权重。数据库里保存用户偏好，也不等于模型被重新训练。

参数是学习到的数值；超参数与推理配置控制过程；上下文是当前计算可使用的输入。三者生命周期不同。

## 4. Token 与表示

文本被分成 token 后映射为向量。token 不是固定等于一个汉字或一个英文单词；不同 tokenizer 的切分、价格与上下文计量可能不同。

Embedding 是数值表示，可以用于比较或检索，但“距离近”不等于命题为真。向量数据库不会自动判断文档是否过期。

## 5. Transformer 的直觉

注意力让一个位置结合其他位置的信息更新表示；多层变换形成更复杂的模式。不能仅凭“注意力”就认定模型有与人类相同的理解机制。实际模型还可能采用稀疏专家、多模态或其他架构细节。

## 6. 生成为什么会错

语言流畅、格式合理、事实正确和任务成功是不同指标。输入缺少证据、问题含糊、训练知识过时、推理步骤错误都可能导致失败。增加模型规模或推理预算不是绝对保证。

## 7. 前端工程师的切入点

先掌握输入契约、状态变化、数据来源和验证。为“生成概念卡”定义：必须有哪些字段、哪些事实需要引用、哪些输出不可直接执行，以及用户怎样纠错。

## 8. 自测

“我把项目规范贴进提示词，模型就学会了公司的知识”可能有哪三种含义？分别判断它是临时上下文、外部记忆，还是参数更新。

参考：仅本轮看见规范属于上下文；保存并检索规范属于外部知识；用样本优化参数才属于训练。产品可能组合三种，但不能凭一次回答判断。

## 9. 数学入口：把模型看成可优化的函数

用最简单的回归理解训练，不必一开始就把 Transformer 当黑箱。

假设模型 y_hat = w × x + b，单个样本损失 L = (y_hat - y)²。前向计算得到预测和损失；反向求导得到参数改变对损失的影响；优化器更新参数。学习率不是“模型聪明程度”，而是更新步长的控制量。

下面是自写教学算例，只有一个样本，不代表真实训练集：

```js
const x = 2, y = 5;
let w = 1, b = 0;
const learningRate = 0.1;

const error = w * x + b - y; // -3
const gradW = 2 * error * x; // -12
const gradB = 2 * error;     // -6
w -= learningRate * gradW;  // 2.2
b -= learningRate * gradB;  // 0.6
// 新预测约 5；一次拟合一个样本不证明泛化。
```

训练集用于更新参数，验证集用于选择方案，测试集用于最终独立判断。若反复依据测试集调参，它就事实上变成验证集。训练损失下降而新样本表现变差，是需要检查过拟合、分布差异和数据泄漏的信号。

## 10. 从分类概率到语言建模

分类模型输出 logits 后，softmax 把它们转为总和为 1 的分布。减去最大 logit 再求指数，可改善数值稳定性，但不改变数学上的 softmax 结果。

对于自回归语言建模，每个位置预测下一个 token。常见训练目标是目标 token 的负对数概率之和或平均值。词表越大不意味着每轮“查一个知识库”；模型是在上下文条件下计算概率。

| 概念 | 不能混同为 |
| --- | --- |
| loss | 用户任务成功率 |
| perplexity | 所有领域都可直接比较的事实准确率 |
| embedding 相似度 | 逻辑蕴含或事实真实性 |
| 采样概率 | 模型对答案正确性的可靠置信度 |
| 训练数据记忆 | 可追溯、实时更新的数据库 |

## 11. 注意力的形状，而不只是术语

设序列长度为 n、隐藏维度为 d。输入表示 X 形状为 n×d；线性变换产生 Q、K、V。单头注意力的教学表达为：

```text
Q = X Wq
K = X Wk
V = X Wv
scores = Q K^T / sqrt(dk) + mask
weights = softmax(scores, 按每个 query 对 key 的维度)
output = weights V
```

Q 表示当前位置怎样查询，K 表示被匹配的特征，V 提供加权组合的内容。这是帮助理解运算的类比，不是数据库键值读取。

自回归模型的 causal mask 阻止一个位置读取未来 token；位置编码/位置机制表达顺序；残差、归一化与前馈网络也参与一个完整 block。不能把一个 attention 公式当作整个大模型。

直接物化 n×n 注意力矩阵会带来二次规模的中间数据；具体实现可通过分块等方式避免完整保存它，但不等于任意精确全注意力的所有计算都自动变成线性。

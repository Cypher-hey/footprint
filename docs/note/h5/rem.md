# CSS 相对单位：rem、em、视口与响应式布局

> 核查日期：2026-10-08。状态：知识修订；未验证真实设备和缩放行为。

## 1. 单位不是布局方案

rem 相对根字体；em 用于 font-size 时通常参照父元素计算字体，用于其他属性时通常参照自身字体。视口单位参照视口，不等于物理屏幕尺寸。

## 2. 选择对比

| 需求 | 候选 | 注意 |
| --- | --- | --- |
| 字体与可访问缩放 | rem / em | 尊重用户字号设置 |
| 容器比例 | %、Grid、Flex | 百分比参照因属性而异 |
| 视口大小 | vw、vh 及动态视口单位 | 移动浏览器 UI 变化 |
| 限制范围 | min/max/clamp | 同时设置合理上下限 |

旧文“字体不能使用 rem”不正确。把根字体强制按宽度缩放是一种历史适配技巧，不是 rem 的定义。

## 3. 示例

```css
.article {
  width: min(100% - 2rem, 70rem);
  margin-inline: auto;
  font-size: 1rem;
  line-height: 1.7;
}
.article h1 {
  font-size: clamp(1.8rem, 1.2rem + 2vw, 3rem);
}
```

示例展示可读宽度和有界字号，不要求安装 JS 布局脚本。验证目标浏览器支持以及文本放大后的效果。

## 4. 常见误区

vw 不意味着所有尺寸必须随屏幕线性缩放；固定像素也不等于不可访问；关键是文本能否放大、重排并保持操作可达。不要通过禁止用户缩放来掩盖布局问题。

## 5. 练习与来源

测试窄屏、横屏、长标题、200% 文本/页面缩放和不同根字体。检查是否截断、横向溢出或按钮不可见。

# 渐进增强与优雅降级

> 审阅日期：2026-10-08。状态：概念修订。

## 1. 区别

渐进增强从可访问的核心内容与基本交互开始，按能力增加体验；优雅降级先实现完整体验，再为缺少能力的环境提供可接受回退。二者都需要从一开始明确支持范围，不是把旧浏览器测试一律拖到最后。

## 2. 例子

知识卡片先能阅读文本，再增强为互动测验和图表。图表解析失败仍能看到结论；流式连接断开仍能保留已确认内容。它不要求每个平台功能完全相同，但核心任务应可完成。

## 3. 验证

关闭 JavaScript、慢网、辅助技术、缺少新 API 时，检查核心内容与操作是否仍可用。能力检测优先于盲目按浏览器品牌分支。

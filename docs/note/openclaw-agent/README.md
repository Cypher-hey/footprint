## 📁 配置说明

每个 Agent 实例包含以下核心配置文件：

- **SOUL.md** - Agent 核心人格定义
- **AGENTS.md** - 工作空间规范
- **USER.md** - 用户信息
- **IDENTITY.md** - Agent 身份定义
- **TOOLS.md** - 本地工具配置
- **BOOTSTRAP.md** - 初始化指南
- **MEMORY.md** - 长期记忆
- **HEARTBEAT.md** - 心跳任务配置

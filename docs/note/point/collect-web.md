# Web 问答：会话、存储、缓存与协议

> 审阅日期：2026-10-08。状态：重复内容归并，修正过时浏览器额度和绝对化结论。

## 1. Cookie 与 Session 是替代关系吗？

不是。会话标识常通过 Cookie 传输，服务端 Session 保存对应状态。安全性取决于传输、属性、轮换、存储和授权，不是“用 Session 就安全”。

## 2. localStorage 永久吗？

不保证。用户清理、浏览器配额和隐私策略都可能影响保存。Cookie 的约 4 KB 常指单条级别，不是所有浏览器永远只有 20 条。见 [Cookie 与存储](../basis/cookie-storage.md)。

## 3. ETag 保证内容哈希吗？

不保证，它是不透明验证标识。缓存要分存储、新鲜度和验证，no-cache 与 no-store 不同。见 [缓存](../http/cache.md)。

## 4. HTTP/2 / HTTP/3 的变化

二进制分帧与加密不是同一概念；多路复用不能抹去所有拥塞与阻塞。HTTP/3 使用 QUIC。服务端推送的实际支持与采用不能按旧浏览器资料推断。

## 5. JSON 一定比 XML 快吗？

数据模型、重复内容、压缩、解析器和工作负载会改变结果。JSON 常便于 JavaScript 数据交换，XML 适用于带命名空间等结构需求；不要用一个固定速度排序代替选择。

## 6. 状态码和可靠性

204 没有响应内容，304 是条件验证语义，5xx 不一定意味着副作用从未发生。TCP 握手与每个业务响应的确认不是同一层。见 [HTTP 基础](../http/http-concepts.md)。

## 7. 自测

设计一次“请求超时但服务端已完成”的处理流程，说明浏览器存储、HTTP 缓存和应用幂等记录分别承担什么。

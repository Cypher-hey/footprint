# HTML 问答：语义、文档模式与解析

> 审阅日期：2026-10-08。状态：知识纠错，未实测辅助技术。

## 1. 语义化的价值

用标题、导航、按钮、表单等正确表达结构与动作，便于维护和辅助技术理解。语义化有帮助，但不能保证特定 SEO 排名或关键词权重。

## 2. DOCTYPE 做什么？

影响 HTML 文档模式，现代页面使用 <!doctype html>。它不会开启 JavaScript 严格模式。标准、有限怪异、怪异模式的区别见 [文档模式](../specification/dtd.md)。

## 3. HTML 与 XHTML

解析规则由实际文档类型与交付方式决定，不是写成小写、补闭合标签就自动按 XML 解析。XHTML 的 XML 良构约束与无障碍要求是不同层面。

图片 alt 应表达用途；纯装饰图可用空 alt，不能把“图片必须有一段说明文字”当无条件规则。

## 4. 练习

把一个 div 点击区域改成真正按钮，验证键盘、焦点和名称。检查一篇文档没有 CSS 时能否按标题与链接理解结构。
